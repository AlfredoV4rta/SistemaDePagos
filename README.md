# Sistema de Pagos 💰

Sistema web académico para la gestión de pagos y usuarios con control de roles. Permite registrar, consultar y administrar información financiera según los permisos de cada usuario.

## 🌐 Demo en Vivo

**[Clikea para ir al DEMO](https://laempresaav-c2htb9f9ewhrh6eu.brazilsouth-01.azurewebsites.net)**

## 📋 Características

- ✅ Autenticación y gestión de usuarios
- ✅ Sistema de roles (Administrador, Supervisor, Usuario)
- ✅ Registro y seguimiento de pagos
- ✅ Consultas filtradas por permisos
- ✅ Interfaz responsiva apoyado con Github Copilot en Visual Studio
- ✅ Reportes según rol

## 🛠️ Tecnologías

- **Backend**: ASP.NET Core, Entity Framework Core, SQL Server
- **Frontend**: Razor Pages/MVC, Bootstrap
- **Despliegue**: Azure App Service, Azure SQL Database

## 👥 Roles

- **Administrador**: Acceso completo y gestión de usuarios
- **Gerente**: Consulta de pagos departamentales y reportes
- **Empleado**: Consulta de información personal y creacion de pago
